# Name options

"OpenPack" is a working name. It clashes with an existing npm package (a Webpack plugin) and
a Rust library on GitHub, both unrelated.

Checked on 2026-11-25: every name below is **free on npm**. A web search found nothing using
"thutapack", "shwepack" or "lanpack". They were **not** checked for trademarks, domain names
or GitHub organisation names: do that for the one you pick.

| Name | Meaning | Notes |
|---|---|---|
| **ThutaPack** | သုတ (thuta) = general knowledge | Says what it is. Easy to say in Burmese and English. My first choice. |
| **LanPya** | လမ်းပြ = guide, one who shows the way | Short, warm. Does not say "offline" or "pack". |
| **ShwePack** | ရွှေ = gold | Friendly and very Burmese, but "Shwe" is used by many businesses. |
| **Pyinnya Pack** | ပညာ = education, wisdom | Clear, but sounds like school only. |
| **LanPack** | local network pack | Technical, means nothing to readers. |
| OpenPack (keep) | | No change needed. Fine while the project is small. |

Renaming touches: the GitHub repository (old links redirect), `package.json`, the server
program names, the START files, window titles and the README. About an hour of work, and the
tests catch anything missed.
