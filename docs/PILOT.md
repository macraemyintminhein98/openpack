# Pilot plan

A small test with real people before wider distribution. Aim: find what confuses people and
what they actually open. Two weeks, one place, 5 to 10 people.

## Before

- [ ] Health review done for the lessons in the pilot pack (`lesson-review.md`), or keep the
      "not checked" notice and tell participants.
- [ ] Burmese labels reviewed by a native speaker (`burmese-review.csv`).
- [ ] `DEVICE-TEST.md` passed on one cheap Android phone and one Zawgyi-font phone.
- [ ] Pack signed with the real key. Public key given to the pilot hub by hand.
- [ ] One helper on site who can answer questions in Burmese.

## Who

5 to 10 people, on purpose a mix: someone over 55, someone who rarely uses a phone, a
teenager, a shop owner, a parent. At least half women. Do not pick only friends who are good
with technology.

## Day 1 (30 minutes per person)

Give them the pack on their own phone. **Do not explain anything.** Ask them to do these and
only watch. Write down where they hesitate, tap the wrong thing, or give up.

| Task | Done alone? | Where did they get stuck? |
|---|---|---|
| 1. Open the library | | |
| 2. Find the lesson about making water safe | | |
| 3. Go through it to the last step | | |
| 4. Make the writing bigger | | |
| 5. Search for a word of their choice | | |
| 6. Give the library to another phone | | |

## Days 2 to 14

They keep it and use it as they like. No tasks.

## End (15 minutes per person)

1. What did you open most? / ဘာကို အများဆုံး ဖွင့်ကြည့်ခဲ့ပါသလဲ။
2. Was any word or sentence hard to understand? Which? / နားလည်ရခက်သော စကားလုံး သို့မဟုတ် စာကြောင်း ရှိပါသလား။ ဘယ်ဟာလဲ။
3. Was anything wrong, or different from what you know? / မှားနေသည်၊ သို့မဟုတ် သင်သိထားသည်နှင့် ကွဲလွဲသည့်အရာ ရှိပါသလား။
4. Did you share it with anyone? How? / တစ်စုံတစ်ယောက်ကို မျှဝေခဲ့ပါသလား။ ဘယ်လို မျှဝေခဲ့ပါသလဲ။
5. What would you like to find in it next time? / နောက်တစ်ကြိမ် ဘာတွေ ပါစေချင်ပါသလဲ။

Record answers on paper, without names.

## Decide

- A task that 3 or more people could not do alone is a bug: fix it before going wider.
- Any report of wrong health content: stop, check with the reviewer, fix, re-release.
- If people shared it onward without being asked, the format works.
