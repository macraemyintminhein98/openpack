# OpenPack (မြန်မာ)

> ဤစာကို AI ဖြင့် ရေးသားထားပါသည်။ မြန်မာစာ အမှားများ တွေ့ပါက ပြင်ဆင်ပေးပါရန် ဖိတ်ခေါ်ပါသည်။

OpenPack သည် အင်တာနက် မရှိသော၊ သို့မဟုတ် ဒေတာဈေးကြီးသော နေရာများအတွက် ပညာရေး၊ ကျန်းမာရေး၊
ဗဟုသုတ စသည့် အကြောင်းအရာများကို USB၊ မန်မိုရီကတ် သို့မဟုတ် ဖုန်း Hotspot မှတစ်ဆင့်
မျှဝေနိုင်သော အခမဲ့ open-source ဆော့ဖ်ဝဲ ဖြစ်ပါသည်။

## အသုံးပြုပုံ

1. `OpenPack-...` ဖိုလ်ဒါကို ဖုန်း သို့မဟုတ် ကွန်ပျူတာသို့ ကူးပါ။
2. `pack` ဖိုလ်ဒါထဲရှိ `index.html` ကို Chrome ဖြင့် ဖွင့်ပါ။ အင်တာနက် မလိုပါ။
3. အခြားသူများကို မျှဝေလိုလျှင် `START` ဖိုင်ကို ဖွင့်ပါ (Windows: `START-WINDOWS.bat`၊
   Android: Termux တွင် `sh START-ANDROID.sh`)။ ထို့နောက် Hotspot ဖွင့်ပြီး QR ကုဒ်ကို စကင်ဖတ်ခိုင်းပါ။

## အရေးကြီးသော အချက်များ

- ခိုးကူး ရုပ်ရှင်၊ သီချင်း၊ စာအုပ်များ မပါဝင်ပါ။ မျှဝေခွင့်ရှိသော အကြောင်းအရာများသာ ပါဝင်ပါသည်။
- မည်သူ ဘာဖတ်သည်ကို မှတ်တမ်းမတင်ပါ။ အကောင့်ဖွင့်ရန် မလိုပါ။
- မြန်မာစာအားလုံးသည် ယူနီကုဒ် ဖြစ်ပါသည်။ ဇော်ဂျီဖုန်းများတွင်လည်း မှန်ကန်စွာ ပေါ်စေရန် ဖောင့်ကို ထည့်သွင်းပေးထားပါသည်။

## ကူညီလိုပါက

မြန်မာစာ စကားလုံးများကို စစ်ဆေးပေးခြင်းသည် အလိုအပ်ဆုံး အကူအညီ ဖြစ်ပါသည်။
`docs/burmese-review.csv` ကို ဖွင့်၍ အမှားပြင်ချက်များ ရေးပေးနိုင်ပါသည်။

အပြည့်အစုံကို [README.md](README.md) (အင်္ဂလိပ်) တွင် ဖတ်ပါ။
